# ALGOFINEX — DESIGN SYSTEM WORKING SPEC

This is intentionally a working system, not a final locked palette.

## Layout

Use a strong central content grid with generous outer margins.

Prefer:
- asymmetric compositions
- large visual objects
- controlled overlap
- varied section heights
- editorial spacing

Avoid:
- every section being a centered 3-column grid
- excessive rounded cards
- identical section templates

## Surfaces

Marketing surfaces should be visually quiet.

Product surfaces may be denser.

Use borders and shadows sparingly.

## Radius

Start with a restrained radius family:
- small: 8px
- medium: 14px
- large: 22px
- product frame: 24–32px

Do not round everything.

## Borders

Prefer subtle 1px borders with low-contrast neutral tones.

## Shadows

Use depth selectively.

Avoid default Tailwind-style shadow-heavy cards everywhere.

## Buttons

Primary CTA should feel like a physical control.

Requirements:
- strong label
- clear hover state
- small directional affordance where appropriate
- no excessive glow

Secondary CTA should remain visually quiet.

## Product UI

Marketing UI can be simplified demo UI.

Never fake a claim by presenting decorative demo numbers as real business performance.

Use labels such as:
- Demo
- Sample
- Illustrative

where necessary.

## Icons

Use one icon family consistently.

Do not mix unrelated icon styles.

## Charts

Charts should feel like product instrumentation rather than decorative artwork.

Prefer:
- meaningful axes
- restrained grid
- readable labels
- clear signal markers
- intentional hierarchy

## Color

Do not finalize the palette from this document alone.

The hero exploration should determine:
- base background
- accent
- chart colors
- positive/negative states
- surface colors

The final system must define all colors as tokens.
